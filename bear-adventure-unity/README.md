# Медведь-Приключенец (Unity, Android)

Оригинальный 3D-платформер в духе мобильных игр про медведя: ходьба, двойной прыжок, удар-вращение,
монеты, патрулирующие враги, платформы к горшку с мёдом. Весь мир строится из примитивов прямо в коде,
поэтому сцену в редакторе собирать не нужно.

**Важно:** проект написан без запуска в Unity (в окружении разработки Unity и Android SDK нет),
поэтому могут понадобиться мелкие правки при первой сборке.

## Как собрать APK

1. Установите Unity Hub и Unity 2022.3 LTS (или новее) с модулем **Android Build Support**.
2. Создайте новый проект по шаблону **3D (Built-in Render Pipeline)**.
3. Скопируйте папку `Assets/Scripts` из этого репозитория в `Assets/` вашего проекта.
4. `Edit → Project Settings → Player → Other Settings`:
   - **Active Input Handling** = `Input Manager (Old)` или `Both` (после смены Unity перезапустится);
   - Default Orientation = `Landscape Left`.
5. `File → Build Settings → Android → Add Open Scenes` (подойдёт пустая сцена `SampleScene`) → `Build`.
   Установите полученный `.apk` на телефон (включите установку из неизвестных источников).

Проверка на ПК: кнопка Play в редакторе — WASD ходьба, Пробел прыжок (двойной в воздухе), E удар,
правая кнопка мыши + движение — камера, Q/R — поворот камеры.

## Управление на телефоне

- Левая часть экрана — плавающий стик.
- Правая часть — перетаскивание камеры; кнопки «ПРЫЖОК» и «УДАР».
- Врага можно победить прыжком сверху или ударом.
