# SkinWatch — цены на скины CS2 и скидки на игры в Telegram

**Что умеет бот:**

- 🔍 **Цены на скин** — пишешь название («AK-47 Redline FT», «калаш редлайн», «керамбит допплер») и видишь цены
  на Маркете CS, Lis-Skins, Skinport (и Avan.Market, если подключён) и в Steam. Лучшая цена отмечена 👈.
- 📊 **Оценка рынка** — стоит ли покупать или продавать по текущей цене: сравнение с обычной ценой, тренд за неделю, ликвидность.
- 🔔 **Уведомления** — «🔔 Следить»: бот сам подбирает порог под цену предмета (дешёвые ±15%, дорогие ±5%).
  Или своё условие: ±5/10/20% или «ниже / выше N ₽» на конкретной площадке.
- 💼 **Инвентарь CS2** — стоимость, самые дорогие предметы, изменение за сутки, плюс лоты, отмеченные как «продаю в Steam».
  **По умолчанию** бот сам сообщает, когда цена предметов инвентаря заметно выросла или упала (порог зависит от цены предмета,
  мелочь дешевле `INV_ALERT_MIN_RUB` не присылает, все изменения — одним сообщением). Выключается в ⚙️ Настройках.
- 🎮 **Вишлист игр** — скидки Steam в выбранном регионе (Россия, Казахстан, Турция…), цена в валюте региона с примерной суммой в рублях,
  рейтинг Steam и Metacritic, совет «брать сейчас или подождать» по истории скидок, поиск с исправлением названий («гта 5» → GTA V).
- 💬 **Поддержка** — пользователь пишет вопрос, вам он приходит в бота, вы отвечаете через «Ответить».

- 💰 **Цена по рынку** в карточке скина: средняя цена на площадках без оверпрайса, «покупают в среднем за», ликвидность
  и рекомендуемая цена продажи.
- 📄 **Экспорт в таблицу** (CSV для Excel): уведомления, инвентарь, вишлист.

Три тарифа — 🆓 Бесплатный, ⭐ ПРО и 💎 УЛЬТРА, подробно в разделе [«Тарифы»](#тарифы-бесплатный-про-ультра).
Все цены и лимиты настраиваются в `.env`.

**Режим «всё открыто» (по умолчанию):** `FREE_FOR_ALL=1`. У всех пользователей лимиты УЛЬТРА, а кнопки, команды
и тексты про тарифы и оплату нигде не показываются. Когда будете готовы брать деньги, поставьте `FREE_FOR_ALL=0`,
подключите ЮMoney (см. ниже) и перезапустите бота.

## Запуск на Windows

Нужен Node.js 22.13+ (https://nodejs.org → LTS). Проверить версию: `node -v`.

```powershell
cd tracker-bot
Copy-Item .env.example .env
notepad .env          # впишите BOT_TOKEN, сохраните
npm test              # 26 тестов
npm start
```

1. Напишите боту `/id`, впишите число в `ADMIN_CHAT_IDS` в `.env` и перезапустите бота (Ctrl+C, затем `npm start`).
2. При первом запуске бот загружает цены площадок, это займёт около минуты. До этого поиск скинов пишет «Загружаю цены».

Бот работает, пока открыт PowerShell. Для работы 24/7 перенесите его на VPS (от ~200 ₽/мес).
Домен и HTTPS не нужны.

## Перенос на свой сервер (VPS)

Подойдёт любой VPS с Ubuntu 22.04/24.04, 1 ядро, 1 ГБ памяти (~200–500 ₽/мес). Лучше в Европе (Нидерланды, Германия, Финляндия) —
оттуда стабильно открываются все площадки. Домен и HTTPS не нужны.

1. **Остановите бота на компьютере** (Ctrl+C) — два запущенных бота с одним токеном мешают друг другу.
2. **Подключитесь к серверу** из PowerShell: `ssh root@IP_СЕРВЕРА` (пароль — из письма хостинга).
3. **Установите Node.js 22:**
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
   apt install -y nodejs
   node -v   # должно быть v22.13 или новее
   ```
4. **Скопируйте папку бота** (в новом окне PowerShell на своём компьютере, вместе с `.env` и `data`):
   ```powershell
   scp -r "C:\Users\Дмитрий\Desktop\tracker-bot" root@IP_СЕРВЕРА:/opt/
   ```
5. **Запустите как сервис** (снова на сервере):
   ```bash
   cd /opt/tracker-bot
   npm run check                                   # самопроверка
   cp deploy/skinwatch.service /etc/systemd/system/
   systemctl daemon-reload && systemctl enable --now skinwatch
   journalctl -u skinwatch -f                      # логи (выход — Ctrl+C)
   ```
   Бот работает 24/7 и сам перезапускается после сбоя или перезагрузки сервера.
6. **Резервная копия базы** раз в сутки: `crontab -e` и добавьте строку `0 4 * * * /opt/tracker-bot/deploy/backup.sh`.

**Обновление на сервере:** скопируйте новую папку `src` (и `package.json`), не трогая `.env` и `data`:
```powershell
scp -r "C:\путь\к\новой\tracker-bot\src" root@IP_СЕРВЕРА:/opt/tracker-bot/
```
затем на сервере `systemctl restart skinwatch`.

## Подключение ЮMoney

Деньги приходят на ваш кошелёк ЮMoney. Бот сам находит платёж по уникальной метке и включает оплаченный тариф.
Сервер и вебхуки для этого не нужны.

1. Кошелёк должен быть **идентифицирован** (именной или идентифицированный статус), иначе он может не принимать переводы.
2. Выполните в папке бота:
   ```powershell
   npm run yoomoney
   ```
   Скрипт по шагам:
   - попросит зарегистрировать приложение на https://yoomoney.ru/myservices/new
     (Redirect URI — `https://t.me`, галочку client_secret не ставить) и вставить `client_id`;
   - даст ссылку. Откройте её, войдите в ЮMoney и нажмите «Разрешить»;
   - браузер откроет `https://t.me/?code=…`. Скопируйте этот адрес целиком и вставьте в окно скрипта.
3. Скрипт сам запишет `YOOMONEY_WALLET` и `YOOMONEY_TOKEN` в `.env`. Перезапустите бота. В консоли должна появиться строка
   `💳 ЮMoney подключён: кошелёк 4100…`.

Токен даёт право **только читать** историю операций и информацию о кошельке. Переводить деньги с его помощью нельзя.
Всё равно никому его не показывайте.

**Как это выглядит для пользователя:** «⭐ Премиум» → «Оплатить 199 ₽» → «Оплатить картой».
Открывается страница ЮMoney, пользователь платит, и в течение 1–2 минут бот пишет «Премиум активен до …».
Вам приходит уведомление «💰 ЮMoney: @user оплатил ПРО — 99 ₽ (пришло 96 ₽)».

- **Комиссия:** за оплату картой ЮMoney удерживает около 3% с получателя, поэтому на кошелёк приходит чуть меньше.
- **Если пользователь вручную уменьшит сумму на странице оплаты,** тариф не выдастся, а бот сообщит вам.
- **Возврат по ЮMoney** делается вручную из кошелька. `/refund` работает только для Stars.

## ⚠️ Важно про оплату

- **Правила Telegram.** Telegram требует, чтобы цифровые товары и подписки в ботах оплачивались звёздами (Stars).
  Оплата по внешней ссылке (ЮMoney) формально нарушает эти правила. На практике многие боты так работают, но есть риск,
  что бота ограничат после жалоб. Поэтому в боте оставлены оба способа: ЮMoney и Stars. Если хотите принимать
  только ЮMoney, поставьте `PREMIUM_STARS=0`, но риск останется.
- **Налоги (самозанятый).** На **каждую** оплату нужно пробить чек в приложении «Мой налог»: услуга «Доступ к премиум-функциям
  Telegram-бота», сумма — сколько заплатил покупатель. Бот напоминает об этом в уведомлении об оплате. Доход от Stars
  тоже нужно отражать.
- **Автосписания.** ЮMoney — разовый платёж на 30 дней, повторная оплата продлевает срок. Stars — подписка, Telegram продлевает её сам,
  пока пользователь её не отменит.

## Тарифы: Бесплатный, ПРО, УЛЬТРА

Включаются в `.env`: `FREE_FOR_ALL=0`. Все цены и лимиты — в `.env` (раздел «Тарифы»), менять можно без правки кода.

| | 🆓 Бесплатный | ⭐ ПРО — 99 ₽ / 50 ⭐ | 💎 УЛЬТРА — 999 ₽ / 500 ⭐ |
|---|---|---|---|
| Скины в уведомлениях | 10, проверка раз в 30 мин | 50, каждые 5 мин | без ограничений, каждый цикл цен (`PRICE_REFRESH_MIN`) |
| Игры в вишлисте | 10, скидки раз в час | 50, каждые 30 мин | без ограничений, каждые 30 мин |
| Карточка скина | средняя цена на площадках | + ликвидность, «покупают за», рекомендуемая цена | то же |
| 📊 Оценка рынка, 📈 Что купить | — | ✅ | ✅ |
| 📄 Экспорт в таблицу (CSV) | — | ✅ | ✅ |
| Обновление инвентаря | раз в 6 ч | раз в час | раз в 15 мин |
| 🪓 Скины Rust и 🎩 TF2 | — | — | ✅ |
| 💳 Где выгодно пополнить Steam | — | — | ✅ |
| 💰 Где выгоднее продать, 🟢 сигналы, 📋 отчёт по инвентарю, 📈 график | — | — | ✅ |
| 💬 Закрытый чат, ранний доступ | — | — | ✅ |

- **Оплата.** Stars — подписка с продлением каждые 30 дней (отменить: Telegram → Настройки → Мои звёзды → Подписки).
  ЮMoney — разово на месяц. Разовая оплата звёздами вместо подписки — `STARS_SUBSCRIPTION=0`.
- **Переход ПРО → УЛЬТРА.** Оставшиеся дни ПРО пересчитываются в дни УЛЬТРА по цене (30 дней ПРО за 99 ₽ ≈ 3 дня УЛЬТРА за 999 ₽)
  и добавляются к оплаченному месяцу. Подписка ПРО звёздами при этом отменяется сама. Купить ПРО при активной УЛЬТРА нельзя.
- **Старые подписчики «Премиума»** считаются ПРО. Старые `PREMIUM_PRICE_RUB`, `PREMIUM_STARS`, `PREMIUM_ALERTS` в `.env` тоже работают
  как настройки ПРО — **если хотите новые цены, замените их на `PRO_PRICE_RUB=99` и `PRO_STARS=50`**.
- `/refund user_id` возвращает последний платёж звёздами и отменяет автопродление. Звёзды выводятся через Fragment примерно через 21 день.
  На каждый платёж — чек в «Мой налог».
- **Частота для УЛЬТРА.** Цены площадок бот скачивает раз в `PRICE_REFRESH_MIN` минут для всех сразу, поэтому чаще этого уведомления
  прийти не могут. `PRICE_REFRESH_MIN=1` — «каждую минуту», но площадки могут начать ограничивать запросы; Skinport в любом случае
  обновляется раз в 15 мин.

### Цена по рынку в карточке скина

```
📊 Средняя цена на площадках: 50 ₽ (без оверпрайса)
🛒 Покупают в среднем за: 40 ₽ (продажи Skinport за 7 дней)
💧 Ликвидность: ВЫСОКАЯ (≈35 продаж в день, Steam)
💡 Рекомендуем выставить за: 45 ₽
```

- **Средняя цена** — медиана самых дешёвых предложений на площадках. Предложение дороже этой медианы больше чем на 50% считается
  оверпрайсом и не учитывается.
- **«Покупают за»** — медиана реальных продаж: Skinport за 7 дней (если продаж мало — за 30), иначе медиана продаж в Steam.
- **Ликвидность** — продаж в день (Steam за сутки, иначе Skinport за неделю / 7): от 20 — высокая, от 3 — средняя, меньше — низкая.
- **Рекомендуемая цена** — середина между «покупают за» и средней ценой (при низкой ликвидности — ближе к цене продаж),
  но не дороже самого дешёвого конкурента и не дешевле «покупают за». Если продажи известны только по Steam — рекомендация для Steam.

Бесплатный тариф видит только среднюю цену, остальное — с ПРО.

### УЛЬТРА: что внутри

- **🪓 Rust и 🎩 TF2.** Поиск, карточка, уведомления и цена по рынку для скинов этих игр. Цены — из Steam и Skinport
  (Skinport отдаёт другие игры по `app_id`; проверьте на сервере: `npm run check` покажет, сколько предметов пришло).
  Открытых выгрузок Маркета CS (tf2.tm, rust.tm) и Lis-Skins для этих игр я не нашёл. Если найдёте ссылку на JSON с ценами —
  впишите в `RUST_PRICES_URL` / `TF2_PRICES_URL`, бот покажет её как «Доп. площадка». Инвентарь пока только CS2.
- **💳 Где выгодно пополнить Steam** (`/topup`, кнопка в меню):
  - *через скины* — купить на площадке и продать в Steam. Курс = цена покупки / сколько придёт на кошелёк. Цена продажи — по реальным
    продажам в Steam (не дороже самого дешёвого лота и медианы продаж), комиссия Steam 13% вычтена. Steam отвечает ~20 раз в минуту,
    поэтому бот раз в час проверяет `TOPUP_STEAM_BATCH` самых ходовых скинов, подборка накапливается постепенно;
  - *сервисы пополнения* — список с комиссиями ведёте вы: `/topup_add Название | 8 | ссылка`, `/topup_del id`, `/topup_list`.
    Открытых данных о комиссиях сервисов нет, поэтому обновляйте их сами (бот показывает дату обновления).
- **💰 Где выгоднее продать** — в карточке скина: сколько придёт на руки на Skinport (если указана `SKINPORT_SELL_FEE_PCT`)
  и на кошелёк Steam, по реальным продажам.
- **🟢 Сигналы** (раз в 15 минут, по одному предмету — не чаще раза в сутки):
  «выгодно купить» — по скинам из уведомлений, если лучшая цена ниже цены продаж на `SIGNAL_BUY_PCT`%;
  «пора продавать» — по инвентарю, если продажи за неделю выше месяца на `SIGNAL_SELL_PCT`%. Только при высокой или средней ликвидности.
- **📋 Отчёт по инвентарю** — раз в день в `REPORT_HOUR`: стоимость, изменение за сутки и неделю, что подорожало и подешевело,
  что выгодно продать. Сигналы и отчёт выключаются в ⚙️ Настройках или кнопкой под сообщением.
- **📈 График цены** — кнопка в карточке скина: лучшая цена на площадках за 30 дней (бот записывает её раз в день,
  поэтому у новых предметов график появляется через пару дней).

### Экспорт в таблицу

Кнопка «📄 Таблица (CSV)» в уведомлениях, инвентаре и вишлисте, или `/export`. Файл открывается в Excel и Google Таблицах;
для скинов в нём та же цена по рынку: средняя, «покупают за», ликвидность, рекомендуемая цена.

### Закрытый чат УЛЬТРА

1. Создайте группу в Telegram (она станет супергруппой, когда включите вступление по заявкам или сделаете её публичной — достаточно
   добавить бота админом).
2. Добавьте бота в группу **администратором** с правами «Пригласительные ссылки» и «Блокировка участников».
3. Узнайте id группы: добавьте в неё, например, @getidsbot (и удалите после) — id вида `-1001234567890`.
4. Впишите в `.env`: `ULTRA_CHAT_ID=-1001234567890` и перезапустите бота.

Дальше всё сам: у подписчиков УЛЬТРА появляется кнопка «💬 Чат УЛЬТРА» (и команда `/chat`) со ссылкой-заявкой. Бот одобряет заявку,
только если УЛЬТРА активен, а раз в 10 минут убирает из чата тех, у кого подписка закончилась (без вечного бана — продлит и вернётся).

**Как работает «Что купить».** Берём предметы с хорошей ликвидностью (от `INVEST_MIN_VOLUME` продаж в неделю) и сравниваем текущую цену
Skinport с медианой его продаж за месяц. «Ниже обычной цены» — дешевле медианы на 5–40% и без падения за неделю; «В росте» — медиана недели
выше медианы месяца на 8%+. Показываем, где купить дешевле всего. Это эвристика, а не финансовый совет — бот так и пишет.

## Оформление бота

- **Описание** («Что умеет этот бот?») и **короткое описание** бот выставляет сам при каждом запуске.
  Свой текст можно задать в `.env`: `BOT_DESCRIPTION=…` и `BOT_SHORT_DESCRIPTION=…`.
- **Аватарка** — `assets/avatar.png` (640×640). Telegram не даёт боту ставить себе фото, поэтому её загружаете вы:
  @BotFather → `/mybots` → ваш бот → Edit Bot → Edit Botpic → отправьте файл.
- **Картинка в описании** (её видно в пустом чате до «Старт») — `assets/description.png` (640×360):
  @BotFather → Edit Bot → Edit Description Picture.
- Исходники картинок — `assets/*.svg`, их можно править в любом редакторе.

## Администрирование (из `ADMIN_CHAT_IDS`)

| Команда | Что делает |
|---|---|
| `/stats` | пользователи, источники, уведомления, инвентари, тарифы, оплаты, состояние каталога |
| `/broadcast [all\|paid\|pro\|ultra\|free] текст` | рассылка всем / платящим / ПРО / УЛЬТРА / бесплатным |
| `/give user_id дней [pro\|ultra]` | подарить или продлить тариф (по умолчанию ПРО) |
| `/topup_add Название \| комиссия % \| ссылка`, `/topup_del id`, `/topup_list` | сервисы пополнения Steam для УЛЬТРА |
| `/refund user_id` | вернуть последнюю оплату звёздами |
| `/check` | обновить цены, проверить уведомления, скидки и оплаты прямо сейчас |

**Ссылки с меткой источника:** `https://t.me/<бот>?start=vk1`. В `/stats` видно, откуда приходят пользователи
и сколько из них платят.

## Поддержка

Пользователь нажимает «💬 Поддержка» (или `/support`) и пишет вопрос. Вам приходит сообщение «💬 Обращение от @user».
Ответьте на него через «Ответить» (свайп влево по сообщению) — ответ уйдёт пользователю. Или командой `/reply user_id текст`.

| Skinport | `api.skinport.com/v1/items` + история продаж за 7/30/90 дней (для оценки рынка) | цены — 5 мин, история — раз в час |

| Курсы валют | ЦБ РФ (`cbr-xml-daily.ru`) | раз в 6 ч |
| Игры: рейтинг | отзывы Steam (`appreviews`) и Metacritic из магазина | раз в неделю |
| Игры: история скидок | CheapShark (минимальная цена за всё время) + скидки, которые видел сам бот | раз в неделю |
| Steam | `priceoverview`, поштучно (лимит Steam ~20 запросов/мин) | для предметов с уведомлениями на Steam — раз в 30 мин; при открытии карточки |
| Инвентарь | `steamcommunity.com/inventory/<id>/730/2` | по кнопке «Обновить», с лимитом |

Стоимость инвентаря считается по ценам Маркета CS и Skinport. Состав инвентаря обновляется редко, а цены — каждые 5 минут.

## Важно про новые источники

- **Avan.Market** не публикует открытую выгрузку цен — адрес нужно взять в их документации API для партнёров или у поддержки
  и вписать в `AVAN_PRICES_URL`. Бот понимает типичные форматы JSON (массив или `items`, поля name/market_hash_name и price).
  Пока адрес не задан, Avan выключен — бот пишет об этом в консоли при старте.
- **Lis-Skins:** адрес и валюта выгрузки — `LISSKINS_PRICES_URL` и `LISSKINS_CURRENCY`. Если площадка поменяет формат, в консоли будет
  `[цены скинов] … l: ошибка` — пришлите текст.
- **Skinport оставлен:** только у него есть бесплатная история продаж, на ней держится «Оценка рынка», пока бот копит свою историю.
  Убрать можно через `SKIN_SOURCES=c,l,a`.
- **«Стоит ли брать» для игр** опирается на историю скидок: IsThereAnyDeal (если задан `ITAD_API_KEY` — точная история
  именно Steam, ключ бесплатный) или CheapShark (минимум во всех магазинах), плюс распродажи, которые закончились при боте.
  Текущая скидка в историю не входит. Если истории нет, бот честно пишет «сравнить не с чем», а не «лучшая цена».
- **Оценка рынка скинов** — это эвристика, а не финансовый совет; бот так и пишет. Когда будете делать её платной —
  `ANALYSIS_PREMIUM_ONLY=1` (и `FREE_FOR_ALL=0`).

## Если что-то не работает

- **В консоли `[цены скинов] … Маркет CS: ошибка` или `Skinport: ошибка`.** Площадка временно недоступна или изменила API.
  Бот продолжит работать на данных второй площадки. Пришлите текст ошибки.
- **Skinport возвращает ошибку про валюту.** Поставьте `SKINPORT_CURRENCY=USD`. Цены будут в долларах: в карточке это видно,
  но сравнение с рублёвыми площадками будет неверным. Лучше сообщите мне — добавлю конвертацию.
- **Инвентарь не грузится.** Он должен быть открыт в настройках приватности Steam. Если Steam часто отвечает «ограничил запросы»,
  увеличьте `FREE_INV_REFRESH_H`.
- **Бот протестирован на имитации** Steam, площадок и ЮMoney: из среды разработки реальные сервисы были недоступны.
  При первом запуске проверьте поиск скина, инвентарь и тестовую оплату на небольшую сумму.
