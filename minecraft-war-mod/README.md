# WarMod - «Война стран» для Minecraft

Плагин для сервера **Paper 1.20.x** (Java 17+). Игроки выбирают страну или основывают свою, растут по
званиям, копят $, строят крепости, воюют за флаги и играют соло против ИИ-стран.

## Установка (по шагам)

1. **Сервер.** Нужен сервер **Paper 1.20.4** (скачать на papermc.io, запускать с Java 17+). Обычный Vanilla/Forge/Fabric не подойдёт.
2. **Jar-файл плагина** - любым из способов:
   * *Без установки программ:* на GitHub открой вкладку **Actions -> Build WarMod -> последний запуск** и скачай артефакт
     `WarMod-jar` (внутри `WarMod-1.0.0.jar`). Сборку можно запустить вручную кнопкой *Run workflow*.
   * *Самому:* установи JDK 17 и Maven, затем в папке `minecraft-war-mod` выполни `mvn package` -
     готовый файл будет в `target/WarMod-1.0.0.jar`.
3. Положи jar в папку **`plugins/`** сервера и перезапусти сервер (`stop`, потом запуск).
4. В консоли должно появиться `WarMod включён`. Зайди в игру: откроется меню стран.
5. Права: себе выдай оператора (`op ник`), чтобы пользоваться `/war admin ...`. Донатерам, которым нужны бесплатные
   страны, выдай право `warmod.create.free` (плагином прав, например LuckPerms).
6. Настройки - `plugins/WarMod/config.yml`, после правки `/war admin reload`.

Для другой версии Minecraft поменяй `paper-api` в `pom.xml`; на 1.21.3+ переименованы константы
`Attribute.GENERIC_*` (замени на `Attribute.MAX_HEALTH` и т.п.).

## Сохранения

Всё сохраняется автоматически каждые 2 минуты, при остановке сервера и переживает перезапуски:
* `plugins/WarMod/data.json` - страны, бойцы, звания, заслуги, казны, кошельки игроков, очки рейтинга, ИИ-страны;
* `plugins/WarMod/tactics.json` - отряды, маршруты на картах и действующие приказы.

Для резервной копии достаточно скопировать эти два файла. Чтобы начать мир войны заново - останови сервер и удали их.
Тактическая карта (предмет) хранится в мире как обычная карта и после перезапуска работает снова.
Временные вещи не сохраняются: текущие задания `/war task`, предложения службы после захвата и налёты ИИ.

Проверка игровой логики без сервера (страны, цены входа, лимиты, звания, захват):
```bash
javac -d /tmp/out src/main/java/ru/warmod/core/*.java src/test/java/ru/warmod/core/*.java
java -cp /tmp/out ru.warmod.core.CoreSelfTest
```

## Как это играется

При первом входе открывается меню стран. Первыми показаны самые маленькие.

* **Цена входа.** Страна больше средней - вход платный, и деньги идут в её казну. Страна меньше средней -
  тебе доплачивают бонус. Так игроков тянет в малые страны.
* **Лимит страны** = средний онлайн сервера x 2 (50 онлайн -> 100 мест). Множитель в `limits.online-multiplier`.
* **Своя страна** стоит `economy.create-cost` $. С правом `warmod.create.free` создание бесплатное:
  его удобно выдавать из магазина сервера (Tebex и т.п.) за реальные деньги.
  Страна создаётся там, где ты стоишь: ставится флаг (баннер) и территория радиусом `claim-radius`.

### Путь 1 - правитель
`/war create Название [цвет]` -> строишь крепость вокруг флага -> зовёшь людей -> вооружаешь их из казны:
`/war kit <боец> <товар>` (офицер и выше). Казна пополняется взносами (`/war deposit`), входными платами,
трофеями за захваты и компенсациями. Если правитель **погибает**, страна переходит к старшему по званию
и заслугам, а бывший правитель понижается (`ranks.leader-death-loses-country`).

### Путь 2 - солдат
`/war join Страна` -> `/war task` выдаёт задания (убить врагов, добыть руду, зачистить монстров, лечить
аптечками). За них идут $ и заслуги. Деньги **не пропадают при смерти** - копи, покупай технику
(`/war shop`, `/war buy`), быстрее растёшь после гибели.

### Звания
| Звание | Что можно |
|---|---|
| Рядовой | выполняет приказы; танк ему не доверяют |
| Сержант (авто при 100 заслугах) | вся техника, командует рядовыми, выдаёт приказы `/war assign` |
| Офицер (500 заслуг, назначает офицер/генерал) | вооружает войска из казны, повышает, не обязан воевать лично |
| Генерал | увольняет любого, снимает деньги из казны, назначает офицеров; генералов назначает правитель |

Повышение `/war promote`, понижение `/war demote`, увольнение `/war fire`.

### Захват флага
Враг стоит у флага `capture-seconds` секунд, пока рядом нет защитников (игроков страны или её ИИ-солдат).
Появляется босс-бар прогресса. Под защитой новичка (`shield-minutes`) захватить нельзя. Чужие не могут
строить и ломать блоки на территории страны (стены можно разрушить танком). Флаг ломать нельзя.
Когда страна захвачена:
1. Казна достаётся победителю, страна исчезает.
2. Бойцам предлагают служить победителю рядовыми: `/war accept` (`offer-seconds` на решение).
3. За каждого отказавшегося победитель получает компенсацию `compensation-per-refusal` $ в казну.

### Тактика: карта и приказы (сержант и выше)
`/war map` выдаёт **тактическую карту** местности. На ней рисуются флаги (синий - твоя столица, красный -
враги, оранжевый - ИИ), зелёные точки - твои бойцы, жёлтые пронумерованные точки и линии - маршрут.
* **ПКМ по земле** - добавить точку маршрута (до 8). **ЛКМ** - режим приказа: *Выдвижение*, *Атака*, *Оборона*.
* **ПКМ в воздух** - отправить приказ. **Shift+ПКМ** - центрировать карту на себе.
* Кому: `/war order target all|<отряд>|<ник>`. Отряды: `/war squad create|add|remove|list|disband`.
* Командовать можно только теми, кто ниже званием. **Атаку** отдают офицеры и генералы, сержант - выдвижение и оборону.
* Боец видит в чате приказ, над землёй - световой луч в точке, на экране - стрелку и расстояние, компас
  смотрит на точку. Дойдя до точки, идёт к следующей. Выполнив приказ, получает $ из казны и заслуги;
  командир видит отчёт. Режим *Оборона* держит последний рубеж, пока командир не снимет приказ
  (`/war order cancel`).
* Тот же маршрут можно набирать командами: `/war order add|undo|clear|mode|send`.
* **Артиллерия** `/war artillery` (офицер+, 300$ из казны): 8 снарядов по последней точке маршрута через 5 секунд.
  По своей территории бить нельзя; флаги от взрывов защищены.

### Военная техника (`/war shop`, нужно звание)
| Техника | Звание | Что умеет |
|---|---|---|
| Джип | сержант | быстрый конь 40 HP, **пулемёт** (ПКМ из джипа, очередь) |
| БТР | сержант | мул 100 HP с грузовым отсеком, возит припасы |
| Танк | сержант | бронированный 120 HP, **орудие** (ПКМ, перезарядка 3 с, взрыв ломает стены) |
| Бронекатер | сержант | лодка с орудием (ставь на воду) |
| Реактивный ранец | офицер | элитры + ракеты |
На технику могут садиться только сержанты и выше **своей** страны.

### Госпиталь
**Аптечка**: ПКМ по раненому союзнику лечит его; медик получает $ и заслуги.

### Соло против ИИ
`/war solo Название [число ИИ-стран 1-8]` - создаёт твою страну и ИИ-страны вокруг (90-220 блоков). У каждой:
флаг, каменная крепость, гарнизон (рядовые, сержанты, офицеры, генерал-босс по мере роста силы).
ИИ-страны растут со временем, ходят в налёты на твой флаг (`ai.raid-interval-seconds`), воюют между собой, а
захваченные заменяются новыми. Побеждай гарнизон, удерживай флаг и забирай казну. Режим работает и на
мультиплеерном сервере (`/war admin ai <число>`) или выключается `ai.enabled: false`.

### Рейтинг и сайт
`/war top [month|year|all]` - страна месяца/года/за всё время. С `web.enabled: true` на порту `web.port`
поднимается страница рейтинга с генералами (`http://<ip>:8765/`, JSON: `/api/ranking`). Порт открывай
только если нужен публичный сайт.

## Команды
`/war help` покажет полный список: menu, list, info, create, join, leave, accept, balance, pay, deposit,
withdraw, members, promote, demote, fire, shop, buy, kit, task, assign, confirm, setcapital, solo, top, map, squad,
order, artillery,
admin (reload, save, give, disband, ai - право `warmod.admin`).

## Структура
* `ru.warmod.core` - игровая логика без Minecraft (страны, ранги, деньги, цены, захват) + `CoreSelfTest`.
* `ru.warmod` - слой Paper: команды, события, флаги, ИИ, магазин, меню, сайт.
